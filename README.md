# VancoCalc Pro

> A modern vancomycin AUC₂₄-guided dosing calculator. Built on first-order, one-compartment population pharmacokinetics aligned with the **2020 ASHP/IDSA Vancomycin Therapeutic Monitoring Consensus Guideline**.

A product of **TheraIntel** — clinical pharmacy × AI × workflow intelligence.

> [!WARNING]
> For informational and educational use by licensed healthcare professionals only. **Not** a substitute for clinical judgment, professional medical advice, dosing, diagnosis, or treatment.

---

## Stack

| Layer | Choice |
|---|---|

| Language | TypeScript (strict) |
| Styling | Tailwind CSS + custom design tokens |
| Charts | Recharts |
| Icons | lucide-react |

## Deploy on Vercel

1. Push this repo to GitHub.
2. In Vercel: **New Project** → import the repo.
3. **Framework Preset:** Next.js (auto-detected).
4. **Build & Output Settings:** defaults.
5. **Environment Variables:** none required for v0.1.
6. Click **Deploy**.

│   ├── CompareDosing.tsx   Multi-frequency comparison table
│   ├── PredictedPK.tsx     Concentration–time chart (Recharts)
│   ├── KineticParams.tsx   CrCl, Vd, ke, CL, t½, IBW
│   ├── CalcInfo.tsx        Method/model disclosure
│   ├── AboutCard.tsx       Footer card
│   └── Toggle.tsx          Generic toggle-group input
├── lib/
│   ├── types.ts            Domain types
│   ├── units.ts            kg/lb, in/cm, μmol/L ↔ mg/dL

The `lib/` package is intentionally framework-agnostic. It will be lifted into a workspace package when the React Native (Expo) app is added.

## PK methodology

| Parameter | Formula |
|---|---|
| **CrCl** | Cockcroft-Gault, IBW-adjusted (×0.85 if female) |
| **IBW** | Devine: 50 (M) / 45.5 (F) + 2.3 × (height_in − 60) |
| **AdjBW** | IBW + 0.4 × (TBW − IBW) when TBW > 120% IBW |
| **Vd** | 0.7 L/kg (0.8 L/kg if critically ill) |
| **kₑ** | Matzke: 0.00083 × CrCl + 0.0044 (per hour) |
| **CL** | kₑ × Vd |
| **AUC₂₄** | Daily dose ÷ CL |
| **Cₘₐₓ,ₛₛ** | (D / (tᵢₙf · CL)) × (1 − e^(−kₑ·tᵢₙf)) / (1 − e^(−kₑ·τ)) |
| **Cₘᵢₙ,ₛₛ** | Cₘₐₓ × e^(−kₑ·(τ−tᵢₙf)) |
| **Target** | AUC₂₄/MIC 400–600 (MIC = 1 default) |
| **Loading dose** | 20 mg/kg (25 mg/kg if ICU), capped 3000 mg |
| **Max infusion rate** | 1000 mg/hr |
| **Dose rounding** | 250 mg |

Multi-dose concentration–time curve generated by superposition of single-dose contributions.
